- Google Fonts

### What I learned

This project helped me practise building a responsive component from a static design. I used the `<picture>` element to show different product images on mobile and desktop, then changed the card from a vertical layout to a horizontal layout at a wider screen size.

I also used CSS custom properties to keep colors, font sizes, spacing, and border radiuses in one place. This made the styles easier to understand and reuse. Adding `:hover` and `:focus-visible` states taught me how visual feedback can make a button clearer for both mouse and keyboard users.

### Continued development

In future projects, I want to keep improving my responsive layouts, practise choosing consistent spacing values, and learn more about accessible interactive elements. I would also like to become more confident at comparing my finished page with a design and making small visual adjustments.
